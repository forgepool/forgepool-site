# Warum ForgePool auf Azure entsteht

ForgePool wird als Cardano Stake Pool auf Azure aufgebaut. Nicht, weil Azure automatisch die günstigste Plattform ist, sondern weil Betrieb, Automatisierung, Monitoring und Infrastrukturtransparenz hier konsequent zusammengeführt werden können.

## Fokus

- reproduzierbare Infrastruktur
- klare Betriebsverantwortung
- Monitoring und Alerting
- FinOps von Anfang an
- saubere Dokumentation

## Einordnung

Der Pool soll nicht einfach „irgendwo laufen“, sondern nachvollziehbar aufgebaut und öffentlich dokumentiert werden.
